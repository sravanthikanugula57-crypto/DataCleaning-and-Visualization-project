# Data Cleaning & Visualization Project

## Project Overview
This project focuses on cleaning and visualizing an E-commerce dataset using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Data Visualization
- Correlation Heatmap

## Visualizations
- Bar Chart
- Histogram
- Scatter Plot
- Heatmap

## Output
The project successfully processed and analyzed the e-commerce dataset using Python. Data cleaning techniques were applied to improve data quality. Various visualizations were created to identify sales trends, customer review patterns, and relationships between different variables.
